Send to Learn

Capture anything worth reviewing — without opening the app.

1 · Pin the icon so it's always one click away

Browsers can't pin it for you, so:

  1. Chrome / Edge / Brave: click the puzzle-piece 🧩 in the toolbar → find Obsidian Optimizer → click the pin 📌.
  2. Firefox: right-click the toolbar → Customize, or click the extensions icon and pin it.

2 · Sign in

Click the ◆ icon → the gear ⚙ → sign in with your ObsidianOptimizer credentials. The API base is already set to https://obsidianoptimizer.uk/api.

3 · Capture anything

Open the popup and paste — or right-click any selection, link, or page and choose “Send to Learn”. The extension figures out the rest:

  • 📝 Plain text / markdown → saved as a note for review
  • 🔗 A web page link → read & turned into notes
  • 🎬 A YouTube / video link → downloaded to watch offline + notes
  • 📎 A PDF / audio / video link, or a dropped file → saved to your workspace + notes

Everything lands in the Learn page — media to watch/read, and generated notes in your Inbox to review, file, and edit.
